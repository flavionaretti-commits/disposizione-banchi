# Disposizione banchi

PWA per organizzare la disposizione di 24 banchi in aula, assegnare i cognomi degli alunni, effettuare estrazioni casuali, salvare diverse configurazioni ed esportare la pianta in PNG/PDF.

**Ideata e sviluppata dal prof. Flavio Naretti**, referente del plesso Maritano, per uso interno dei colleghi del plesso.

## File principali

- `index.html` — app completa
- `manifest.webmanifest` — configurazione PWA
- `service-worker.js` — funzionamento offline
- `icons/` — icone per Android/iOS/PWA
- `LICENSE` — GNU GPL v3.0 per il software
- `LICENSE-CONTENUTI.md` — condizioni relative ai contenuti non software

## Installazione

Dopo la pubblicazione con GitHub Pages, aprire il sito dal browser del dispositivo e usare la funzione di aggiunta alla schermata Home. La PWA funziona anche offline dopo il primo caricamento completo.

## Privacy

I cognomi, le disposizioni e i salvataggi restano nel browser del dispositivo. La repository non contiene dati degli alunni.
